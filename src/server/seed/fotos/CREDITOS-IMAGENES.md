# Créditos de las imágenes del Prototipo

Registro de autoría, fuente y licencia de las imágenes finales que usa el Prototipo. Las columnas **autor**, **fuente / URL**, **licencia** y **fecha** están VACÍAS a propósito: las llena la persona responsable del proyecto. No se inventan valores.

Los originales viven en `fotos-originales/` (fuera de git) y se preparan con `npm run preparar-fotos` (casos) y `npm run preparar-fotos -- --portada` (portada). Ninguna imagen muestra personas identificables ni perros reales extraviados.
